Projeto de **Análise Exploratória de Dados** (ISCTE), desenvolvido em R com dados em Excel.

## Conteúdo
- `PROJETO AED.Rmd` – código R Markdown do relatório
- `PROJETO-AED.html` – relatório gerado (abrir no navegador)
- `ANALISE EXPLORATORIA DE DADOS.pdf` – versão final em PDF
- `PROJETO AED - DADOS.xlsx` – dados usados na análise
